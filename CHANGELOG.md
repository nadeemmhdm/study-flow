# Changelog

All notable Study Flow changes are documented here.

## [1.0.0] - 2026-10-04

### Added
- React + TypeScript + Vite learning planner.
- Topic and optional goal input.
- Configurable 1–10 stage learning flows.
- Lesson objectives, practice tasks and research shortcuts.
- Completion tracking, progress meter and learning history.
- Local browser persistence and JSON export.
- Professional responsive UI with Framer Motion transitions.
- Reduced-motion accessibility support.
- Windows PowerShell and Linux/macOS installers.
- CLI setup, start, doctor, update-check, update and version commands.
- Safe fast-forward-only updater with dirty-tree protection.
- `SF-xxxx` diagnostic error-code documentation.
- Cross-platform CI build verification.
- Production dependency audit and secret-pattern scan.
- Browser hardening headers and security policy.
